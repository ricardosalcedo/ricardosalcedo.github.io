# Ricardo Salcedo's Personal Website

Personal blog and portfolio, built with [Astro](https://astro.build) and deployed on [GitHub Pages](https://pages.github.com).

## About

I'm Ricardo Salcedo — FPGA Platform Engineer. I build developer infrastructure for satellite networking FPGAs: build fleet orchestration, AI-powered code analysis, lab automation, and cloud-native tooling.

## Tech

- **Languages:** Python, SystemVerilog, TypeScript, Bash, TCL
- **Infra:** AWS (CDK, Batch, Lambda, ECS), Docker, Terraform
- **FPGA:** Vivado, VCS, SpyGlass, StarForge, FuseSoC
- **AI/ML:** Bedrock, Claude, multi-agent orchestration

## Development

```bash
npm install        # Install dependencies
npm run dev        # Dev server at localhost:4321
npm run build      # Production build to ./dist/
npm run preview    # Preview production build
```

## Deployment

Deployed via GitHub Actions to GitHub Pages on push to `main`.
